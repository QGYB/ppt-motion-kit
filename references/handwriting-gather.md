# 手书逐字飞聚

用于开场短题、章名、讲到一个关键问题后的一句回答；不要给长正文和细小图例全部套入。默认庞门正道粗书体6.0，先完成最终排版，再让字聚回该位置并留出读时。

保留可编辑文字。源行为包含按字迭代、随机初始位移、透明度、500%到100%缩放、横纵归位、减速和结束保持。`text-gather-presets.json`保留点击与进页两种原生时序；它们是独立文字技法，未作为额外PPT模块计数。

目标页尚无动画时间树时，可为该页现有文字形状生成时序：

```sh
python scripts/text_gather.py --shape-id 7 --trigger click
python scripts/text_gather.py --shape-id 7 --trigger slide-start
```

把7换成目标文字的真实`cNvPr/@id`。脚本输出`p:timing`，不自动修改PPT。已有其他动画、音轨或路径的页面不可直接覆盖时间树；优先在演示软件中复制完整带动画文字对象，或正确合并节点并重编号。

动作完成时间随字数增加。保留最后一字归位后的阅读时间，核实际点击会推进动画还是翻页。脚本生成XML不代表当前新句子已实播通过。
