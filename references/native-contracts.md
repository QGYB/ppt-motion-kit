# 原生绑定与连续状态

本包的每个模块都是完整调用单元。`modules.json`给出PPT路径、SHA-256、页数、角色、来源限制、绑定清单和历史验证摘要。`bindings/*.json`列出原对象及运行片段，不依赖旧电脑的绝对路径。

## 调用计划

```json
{
  "font_fallback": "Noto Sans SC",
  "components": [
    {
      "module_id": "vid-0299-rhythmic-timeline",
      "object_text_replacements": [
        {"page": 1, "object_id": "实际ID", "expected_text": "原文本", "runs": ["新文本"]}
      ]
    }
  ]
}
```

上例展示字段，ID和运行片段须从`inspect --bindings`读取，不能原样使用。可直接运行的完整示例见`examples`。

- `page`为模块内从1开始的页号；对象ID按该页绑定。
- `expected_text`必须精确匹配源对象；`runs`数量必须与该对象原片段数一致，以保持字号、字体和段落差异。
- 表格绑定附`table_cell: [行, 列]`，索引从0开始；仅更新指定单元格。
- 相同占位文本可能属于不同章节，应按对象语义分组；同一实体的画外和后页副本则须同步。
- 八字开场保持两行各四个原字位；同字出现在多个字位时分别绑定，不能全局替换一个汉字。
- `locked_bindings`中的字孔源文本不可普通改字；更换轮廓需另做几何并实播。本包只承诺原固定字孔。

## 素材与数据

`object_media_replacements`指定原页、对象、媒体部件与源SHA。先看该组件绑定和`image_usage`，避免同一资源的多处引用被意外全部替换。普通换图仍需检查主体裁切、地平线、重复副本和路径末端。增加图数或更改图宽会改变平移关系，不能默认为原接口已经支持。

半环组件`vid-0314-semicircle-spin`有已验证的百分比参数契约。按它的`parameter_contract`同时更新标签和实际圆弧，不只改数字；其他模块未声明的数据或几何参数不能任意设置。

保留完整多页链及原次序。组装器不会因目录中的页地址而允许任意截页，也不会替新接的两个组件自动设计连续运动。新文件的`.reuse.json`记录来源、SHA、字体替换和计时保留情况，实播字段仍为待检查。
